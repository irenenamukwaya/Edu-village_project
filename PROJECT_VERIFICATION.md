```
Start App
    ↓

    ↓

    ↓
Choose a Game
    ↓
    ├─→ Activity Game (10 questions)
    ├─→ Object Game (10 questions)

    └─→ Math Game (mode selection, then 10 questions)
    ↓
Game Play (answer questions, earn coins)
    ↓
Reward Screen (score, praise, coins earned)
    ↓
Play Again ⟲ OR Back to Home
```

## 🚀 Ready to Use Immediately

### To Run:
```bash
cd eduvillage
flutter pub get
flutter run
```

### To Build:
```bash
# Android APK
flutter build apk --release

# iOS
flutter build ios --release

# Web (optional)
flutter build web --release
```

### To Customize:
1. Edit `pubspec.yaml` for metadata

3. Add sounds to `assets/sounds/`
4. Modify colors in `constants.dart`
5. Update questions in JSON files
